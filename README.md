## معرفی

**فاکتور پرو** یک Progressive Web App (PWA) مدرن برای مدیریت فاکتور و پیش‌فاکتور است که بدون نیاز به سرور، اینترنت یا حساب کاربری کار می‌کند.

تمام داده‌ها فقط روی دستگاه کاربر ذخیره می‌شوند. طراحی رابط کاربری با سبک Glassmorphism و تجربه نزدیک به اپلیکیشن‌های بومی موبایل پیاده‌سازی شده است.

مناسب برای:
- فروشگاه‌ها و کسب‌وکارهای کوچک
- فریلنسرها و پیمانکاران
- کسانی که به حریم خصوصی داده اهمیت می‌دهند
- استفاده در محیط‌هایی با اینترنت ناپایدار یا بدون اینترنت

## قابلیت‌ها

### مدیریت اسناد
- ایجاد، ویرایش و حذف **فاکتور** و **پیش‌فاکتور**
- تبدیل پیش‌فاکتور به فاکتور (با حفظ سند اصلی)
- شماره‌گذاری خودکار قابل تنظیم (مثلاً `INV-0001` / `PF-0001`)
- پیش‌نمایش حرفه‌ای سند
- چاپ و ذخیره به‌صورت PDF از طریق مرورگر
- اشتراک‌گذاری متن سند (Web Share API)

### محصولات و مشتریان
- مدیریت کامل محصولات (نام، کد، قیمت، واحد، وضعیت)
- مدیریت مشتریان (نام، شرکت، تلفن، ایمیل، آدرس، شناسه‌های مالیاتی)
- جستجوی سریع محلی

### پروفایل کسب‌وکار
- اطلاعات فروشنده (نام، تلفن، آدرس، شناسه مالیاتی و …)
- آپلود لوگو، مهر و امضا
- نمایش خودکار در پیش‌نمایش و چاپ اسناد

### داده و امنیت
- ذخیره‌سازی محلی با **IndexedDB**
- پشتیبان‌گیری کامل در فایل JSON
- بازیابی امن با تأیید کاربر
- بدون ارسال داده به سرور خارجی

### تجربه کاربری
- طراحی Responsive (موبایل، تبلت، دسکتاپ)
- منوی پایین مخصوص موبایل + دکمه شناور
- حالت **روشن / تاریک / سیستم**
- پشتیبانی کامل RTL و فارسی
- قابلیت نصب به‌عنوان اپ (Add to Home Screen)

## تکنولوژی‌ها

| بخش | انتخاب |
|------|--------|
| رابط کاربری | HTML5 · CSS3 · Vanilla JavaScript (ES Modules) |

## ساختار پروژه

```text
faktor-pro/
├── index.html              # نقطه ورود
├── manifest.json           # تنظیمات PWA
├── sw.js                   # Service Worker
├── icons/                  # آیکون‌های اپ
├── app/
│   ├── core/               # Router, State, Events, Theme, Utilities
│   ├── modules/            # Dashboard, Products, Customers, Invoices, Quotations, Settings
│   ├── services/           # Pricing, PDF Renderer, Share, Backup, Image
│   ├── storage/            # IndexedDB + Repositories
│   └── styles/             # Design Tokens, Layout, Components
└── README.md
```

## نصب و اجرا

### اجرای محلی

```bash
# کلون یا دانلود پروژه
cd faktor-pro

# سرو کردن با Python
python3 -m http.server 8080 --bind 0.0.0.0
```

سپس در مرورگر باز کنید:

```text
http://localhost:8080
```

> به‌خاطر استفاده از ES Modules و Service Worker، پروژه را با `file://` باز نکنید.

### اجرا روی گوشی (همان وای‌فای)

1. سرور را با `--bind 0.0.0.0` اجرا کنید  
2. IP سیستم را پیدا کنید  
3. روی گوشی آدرس `http://IP:8080` را باز کنید  
4. از منوی مرورگر گزینه **Install app** یا **Add to Home Screen** را بزنید  

### استقرار رایگان (GitHub Pages)

1. این ریپازیتوری را Fork یا فایل‌ها را در یک ریپوی جدید آپلود کنید  
2. به **Settings → Pages** بروید  
3. Source را روی branch اصلی و پوشه `/ (root)` قرار دهید  
4. پس از Deploy، آدرس عمومی شما آماده است:

```text
https://USERNAME.github.io/REPO-NAME/
```

همچنین می‌توانید از **Netlify** یا **Cloudflare Pages** با Drag & Drop استفاده کنید.
