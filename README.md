# فاکتور پرو – Offline-First Invoice & Proforma PWA

## نسخه ۰.۷ – آماده موبایل

## اجرا روی کامپیوتر

```bash
cd invoice-pwa
python3 -m http.server 8080
```
باز کنید: http://localhost:8080

## اجرا روی گوشی (همان شبکه وای‌فای)

1. روی کامپیوتر:
```bash
cd invoice-pwa
python3 -m http.server 8080 --bind 0.0.0.0
```

2. IP کامپیوتر را پیدا کنید:
- ویندوز: `ipconfig` → IPv4
- مک/لینوکس: `ifconfig` یا `ip a`

3. روی گوشی در مرورگر باز کنید:
```
http://IP-کامپیوتر:8080
```
مثال: `http://192.168.1.5:8080`

4. نصب به‌عنوان اپ:
- اندروید (Chrome): منو ⋮ → Install app / افزودن به صفحه اصلی
- آیفون (Safari): دکمه Share → Add to Home Screen

## نکات
- گوشی و کامپیوتر باید به یک وای‌فای وصل باشند
- فایروال ویندوز ممکن است پورت 8080 را ببندد؛ در آن صورت Allow کنید
- بعد از نصب PWA، بدون اینترنت هم کار می‌کند
